# Jardín rosado 🌸

Hecho por Anderson, para mi novia.

Campo animado de flores rosadas con una carta al final del recorrido. Diseño adaptable y navegación táctil para teléfonos.

## Abrir localmente
Descarga el repositorio y abre index.html en un navegador, o abre la carpeta en Visual Studio Code y utiliza Live Server. No requiere npm.

## Archivos
- index.html: estructura y estilos.
- scene.js: textos y animación.
- flor-rosada.png: flor transparente.

Desliza hacia arriba o utiliza la rueda del ratón para llegar a la carta. Las fuentes de Google requieren Internet.
